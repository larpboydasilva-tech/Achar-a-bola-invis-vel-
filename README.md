# 🎮 Jogo Encontrei

Um jogo interativo feito com p5.js onde você precisa encontrar uma bola que se move aleatoriamente na tela!

## 📋 Como Jogar

1. Mova seu mouse pela tela
2. Um círculo ao redor do seu mouse mostra a distância até a bola invisível
3. Quando o círculo ficar pequeno, você está perto! 🎯
4. Encontre a bola para vencer! 🎉

## 🛠️ Tecnologias

- **HTML5** - Estrutura da página
- **p5.js** - Biblioteca de gráficos e interação
- **JavaScript** - Lógica do jogo

## 📝 Recursos

- ✨ Bola invisível com movimento aleatório
- 📍 Indicador de proximidade visual
- 🎉 Celebração ao ganhar
- 🎨 Interface simples e intuitiva

## 🚀 Como Usar

Abra o arquivo `index.html` em seu navegador e comece a jogar!
